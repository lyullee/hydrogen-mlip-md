# 검증 기록 — 2026-10-22

이 문서는 프로그램의 실행·수치 처리가 동작하는 범위와 재료 예측 정확도 검증의 차이를 기록합니다.

## 자동 검사

수치 검사 20개와 화면 검사 1개입니다. 수치 검사는 알려진 해석해·합성 궤적·검사용 비물리 포텐셜을 사용합니다. 검사용 포텐셜은 실제 계산기 선택에 노출되지 않습니다.

- Brownian 궤적의 Einstein 관계와 Å²/fs → m²/s 단위 변환
- 모재 질량중심 이동을 가했을 때의 결과 불변성
- 탄도·정지·짧은 궤적에서 D 보류
- 불규칙 시간, NaN, 수소 없음, 질량 오류, 짧은 입력, 부적절한 적합 창 거부
- 포획에너지 참조 상쇄와 양·음 부호
- bcc Fe 예제와 구조 쌍의 조성·셀 검사
- wrapped 궤적 거부, 체크포인트 해시 불일치와 DFT 백엔드 거부
- 실패 실행 기록과 실행 디렉터리 충돌 방지
- 인장 응력 부호·단위·최대응력 감소율, 최대점 미확인 시 보류
- 해석적 이중우물 NEB 장벽 1 eV 재현
- MD 평형화 제외, 정확한 생산 구간 샘플링과 연속 좌표 저장
- 위치 이완 미수렴 시 결과 거부
- 한국어 화면의 네 계산 폼, 합성 데모 그래프, 모델 경로 누락 처리

## 실제 CHGNet CPU 실행 점검

원본 저장소의 CHGNet-0.3.0-MPtrj 체크포인트를 upstream에서 내려받고 SHA-256 `d14ab7c0f093efe64b60a7bcd540bca10e74fb7f46c86108a079af60524659d1`과 일치함을 확인했습니다. 파일은 배포물에 포함하지 않습니다.

Windows / Python 3.12.14 / ASE 3.29.0 / NumPy 2.5.4 / CHGNet 0.4.2 / PyTorch 2.14.1 / Streamlit 1.66.1에서 확인했습니다.

16 Fe + 1 H bcc 예제에 대해:

- 모델 로딩과 유한한 에너지·힘·ASE 응력 출력 확인
- 초기 입력 총에너지 약 −136.8875 eV (이 값은 이완 전 코드 연결 점검값)
- 고정 셀 FIRE 이완 수렴 확인 (`fmax=0.05 eV/Å`, 최대 400 단계)
- 300 K, 0.25 fs, 평형화 20 단계 + 생산 200 단계(50 fs), 시드 42 실행 완료
- `production.traj`, `unwrapped.npz`, `thermodynamics.csv`, 로그, 구조·모델 해시와 결과 JSON 생성 확인
- 생산시간이 10 ps 미만이고 평균온도 약 105 K로 목표온도에서 벗어나므로 **D는 null로 보류**됨을 확인

`validation/chgnet_cpu_smoke/`의 기록은 매우 짧은 실행 점검입니다. 온도 평형화나 확산 물성 수렴을 주장하는 자료가 아닙니다. 설정의 모델 경로는 생성 당시의 로컬 경로이며, 재실행하려면 현재 로컬 모델 경로로 바꾸어야 합니다.

브라우저에서도 프로그램을 열고 한국어 입력 화면과 합성 궤적 데모를 확인했습니다. 합성 데모는 재료 예측값이 아닙니다.

## 아직 검증하지 않은 것

MACE 어댑터의 실제 모델 실행, 실제 MLIP에 의한 포획·NEB·인장 계산의 정량 벤치마크, 장시간 확산 수렴, Fe–H·강종별 실험 오차, 입계·전위·균열 구조에서의 모델 적합성, GPU 실행, 별도 PC의 깨끗한 환경에서 setup.ps1 전체 설치는 검증하지 않았습니다. 이 항목들을 완료된 검증으로 해석하면 안 됩니다.

수치 검사에서 ASE와 NumPy 2.5 조합의 upstream deprecation 경고가 발생합니다. 실행 실패는 관찰하지 않았습니다. CHGNet은 PyTorch 텐서 변환 경고를 출력했으나 유한한 에너지·힘·응력과 MD 실행을 확인했습니다.

## 0.1.1 실행 오류 수정 확인

사용자가 보고한 `로컬 MLIP 모델 파일 경로를 입력하세요` 오류를 재현하는 입력 상태를 확인했습니다. 기본 계산기는 CHGNet으로 바꾸고 설치된 체크포인트 경로를 자동으로 선택합니다. 로컬 `.venv`에 실제 패키지를 설치하고 모델 해시를 확인했습니다. Windows 시작 스크립트는 최초 설치·모델 준비, 이메일 입력 없는 시작, 고정 포트 8511, 이미 실행 중인 동일 앱의 재사용을 처리합니다. 서버 로그는 `.runtime/`에 기록합니다.

기존 21개 검사에 로컬 체크포인트 자동 선택 회귀검사를 추가했습니다. 실제 설치된 `.venv`와 체크포인트로 Streamlit 화면의 `계산 실행`을 눌러 **54 Fe 예제의 네 구조 이완과 포획에너지 계산·결과 저장 완료**를 확인했습니다. 계산된 포획에너지는 약 0.1945 eV이며, 이 결과는 코드 연결 확인 자료로서 수렴·정확도가 검증된 재료값을 의미하지 않습니다. 해당 실행 기록은 `validation/installed_ui_trap/`에 있습니다.

MD·포획·NEB·인장 계산의 진행 상태 표시와 과거 실행 결과 다시 보기도 추가했습니다. CPU 기본 스레드는 2개로 지정해 작은 Fe 셀에서 과도한 스레드 생성으로 느려지는 상황을 줄이고 실제 스레드 수를 모델 실행 기록에 남깁니다.
